# Footer global Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir un componente `<Footer />` global que aparece en todas las páginas, con 4 columnas de enlaces (Social, Empresa, Legal, Apoyo) y la palabra "trama" en tipografía editorial grande, siguiendo el spec aprobado en [2026-05-24-footer-design.md](../specs/2026-05-24-footer-design.md).

**Architecture:** Componente React puro de presentación (sin estado) montado una vez en `AppShell` (`App.tsx`). Estilos en SCSS BEM siguiendo el patrón de `Navbar.scss`. Textos vía i18next reutilizando los namespaces existentes `es/footer.json` y `en/footer.json` (sobreescribiendo su contenido andamiado).

**Tech Stack:** React 19, TypeScript, react-i18next, SCSS (BEM + tokens CSS), Vite. **No hay test suite** en este proyecto — la verificación se hace con `npm run lint`, `npm run build` y revisión visual en navegador (`npm run dev`).

**Convenciones importantes del proyecto:**
- Tokens semánticos (`var(--color-*)`, `var(--space-*)`, `var(--text-*)`) — nunca hardcodear valores.
- BEM (`.block__element--modifier`) y un SCSS por componente, colocado junto al `.tsx`.
- Alias `@/` mapea a `src/`.
- i18n: añadir claves a `es/` Y `en/` siempre.
- **Commits**: el usuario debe aprobar cada commit explícitamente antes de ejecutarlo. Los pasos "Commit" están en el plan para documentar el agrupamiento, pero **NO los ejecutes sin pedir confirmación al usuario**.

## Task 2: Crear el componente `<Footer />`

**Files:**
- Create: `src/components/layout/Footer.tsx`

El componente es de presentación pura: sin estado, sin efectos. Usa `useTranslation()` para los textos. Los enlaces externos (columna Social) abren en pestaña nueva. Los internos van a `href="#"` por ahora (cuando existan las páginas se migran a `<Link>` de react-router).

- [ ] **Step 1: Crear `src/components/layout/Footer.tsx`**

```tsx
import { useTranslation } from "react-i18next";
import "./Footer.scss";

const SOCIAL_LINKS = [
  { key: "instagram", href: "#" },
  { key: "facebook", href: "#" },
  { key: "tiktok", href: "#" },
  { key: "x", href: "#" },
] as const;

const COMPANY_LINKS = [
  { key: "contact", href: "#" },
  { key: "about", href: "#" },
  { key: "privacy", href: "#" },
] as const;

const LEGAL_LINKS = [
  { key: "legalNotice", href: "#" },
  { key: "cookies", href: "#" },
] as const;

const SUPPORT_LINKS = [
  { key: "supportContact", href: "#" },
  { key: "sponsorship", href: "#" },
] as const;

export default function Footer() {
  const { t } = useTranslation();
  const year = new Date().getFullYear();

  return (
    <footer className="footer">
      <div className="footer__inner">
        <nav className="footer__columns" aria-label={t("footer.aria.nav")}>
          <section className="footer__column">
            <h3 className="footer__heading">{t("footer.columns.social")}</h3>
            <ul className="footer__list">
              {SOCIAL_LINKS.map(({ key, href }) => (
                <li key={key}>
                  <a
                    className="footer__link"
                    href={href}
                    target="_blank"
                    rel="noreferrer noopener"
                  >
                    {t(`footer.links.${key}`)}
                  </a>
                </li>
              ))}
            </ul>
          </section>

          <section className="footer__column">
            <h3 className="footer__heading">{t("footer.columns.company")}</h3>
            <ul className="footer__list">
              {COMPANY_LINKS.map(({ key, href }) => (
                <li key={key}>
                  <a className="footer__link" href={href}>
                    {t(`footer.links.${key}`)}
                  </a>
                </li>
              ))}
            </ul>
          </section>

          <section className="footer__column">
            <h3 className="footer__heading">{t("footer.columns.legal")}</h3>
            <ul className="footer__list">
              {LEGAL_LINKS.map(({ key, href }) => (
                <li key={key}>
                  <a className="footer__link" href={href}>
                    {t(`footer.links.${key}`)}
                  </a>
                </li>
              ))}
            </ul>
          </section>

          <section className="footer__column">
            <h3 className="footer__heading">{t("footer.columns.support")}</h3>
            <ul className="footer__list">
              {SUPPORT_LINKS.map(({ key, href }) => (
                <li key={key}>
                  <a className="footer__link" href={href}>
                    {t(`footer.links.${key}`)}
                  </a>
                </li>
              ))}
            </ul>
          </section>
        </nav>

        <div className="footer__brand-mark" aria-hidden="true">
          {t("footer.brandMark")}
        </div>
      </div>

      <div className="footer__bottom">
        <small className="footer__copyright">
          {t("footer.copyright", { year })}
        </small>
      </div>
    </footer>
  );
}
```

## Task 3: Crear los estilos `Footer.scss`

**Files:**
- Create: `src/components/layout/Footer.scss`

Sigue el patrón de [src/components/layout/Navbar.scss](src/components/layout/Navbar.scss): `@use '../../styles/lib' as *` para mixins, BEM, tokens semánticos. El dark theme se hereda automáticamente al usar tokens.

Decisiones de layout (del spec):
- `.footer__inner` es un grid `1fr auto` con `align-items: end`: columnas a la izquierda, marca gigante a la derecha alineada por la base.
- `.footer__columns` es un sub-grid de 4 columnas iguales.
- `.footer__brand-mark` usa `clamp(96px, 18vw, 260px)` para escalar sin overflow.
- `.footer__bottom` es una banda separada con `border-top` sutil.
- En `≤768px` el grid externo colapsa a 1 columna (marca debajo) y las 4 columnas pasan a 2x2.

- [ ] **Step 1: Crear `src/components/layout/Footer.scss`**
